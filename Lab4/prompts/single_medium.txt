Summarize the following system note into five bullet points. KV Cache stores key and value tensors computed during transformer attention. During autoregressive generation, each new token needs to attend to previous tokens. Recomputing all historical key and value tensors would be wasteful, so inference systems keep them in memory. Longer context windows and higher concurrency increase KV Cache memory pressure. Prefix reuse can reduce repeated prefill computation when many requests share the same beginning. A serving system must balance latency, throughput, GPU memory usage, and cache eviction policy.
