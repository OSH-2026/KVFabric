# 2026-06-30 至 2026-07-01 期末汇报材料整理

## 背景

远程 9B 实验和最终 12h 矩阵完成后，项目进入期末汇报准备阶段。这个阶段的工作重心是把代码设计、实验过程、调试工具和结果分析整理成可汇报材料，并明确不同成员负责的内容。

## 材料整理方向

### 1. 当前代码设计

整理 KVFabric 当前在 vLLM 中的接入点和模块边界：

- BlockPool / KVCacheManager 中的 lifecycle side table 与 admission。
- Scheduler 中的 hit-aware promotion、foreground-priority 和 latency guard。
- OpenAI serving 中的 request metadata、header whitelist 和 hint 传递。
- Metrics 中的 Prometheus 指标、JSONL 事件流和 class/segment/SLO 统计。
- 实验工具链中的 trace、loadgen、runner、sync、summary、dashboard 和 replay。

同时对照 vLLM 原始实现，说明 KVFabric 增加了哪些控制面信息，哪些地方保持 vLLM 主流程不变。

### 2. 接手后的迭代过程

迭代过程按问题展开，重点放在实验暴露出的问题和对应代码改进上。最终整理为九个主要问题：

1. 远程长测闭环。
2. 真实化 trace 与 open-loop loadgen。
3. 指标体系升级。
4. Hit-aware positive scheduler。
5. Fairness / latency guard。
6. Run state / dashboard / replay。
7. Unified controller。
8. Admission 路径重构。
9. Latency header plumbing 与 scoring。

每个问题都补充原因、实现修改、验证方式和对后续实验的影响。

### 3. 9B 实验设计

实验设计材料重点说明请求怎样构造、怎样发送、模拟什么场景，以及每个实验验证什么：

- 请求类型：foreground、background、durable、session、cold_rag、decode_heavy、low_reuse 等。
- trace 字段：tenant、family、session、turn、phase、scheduled_at_seconds。
- 发送方式：open-loop replay，固定计划时间，A/B 共享同一 trace。
- 实验层级：小实验用于调试，中等实验用于调参，12h 实验用于验收。
- 指标口径：SLO goodput、class latency、prefix hit、rebuilt-from-eviction、lifecycle summary。

### 4. 结果展示

最终展示围绕 12h 实验矩阵展开。每个 stage 需要说明：

- 场景设计与请求组成。
- 统一 KVFabric controller 下的参数重点。
- 主要指标变化。
- 能证明的性能特性。
- 结果背后的原因分析。

展示重点放在高压、稳定共享前缀、冷热混合和 SLO 边界场景中的收益，同时说明低复用场景下的保护效果。
